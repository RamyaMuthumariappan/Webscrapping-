How to use 
Step 1: Clone the repository
git clone https://github.com/RamyaMuthumariappan/Webscrapping-.git
cd your-repo-name

Step 2: Install all dependencies 
pip install -r requirements.txt

Step 3: Run the analysis
Open web_scraping.ipynb in Jupyter Lab or Google Colab and run all cells.
